# 公众号自动驾驶（gzh-autopilot）

把「选题 → 写稿 → 存草稿箱」整条流水线自动化。用户只需要说话，AI 跑脚本。

**适用对象**：有微信公众号（个人订阅号即可）的人。没认证也能用草稿箱接口。

---

## AI 使用守则（必须逐条遵守，用户当小学生对待）

### 第 0 步：技能加载后立刻做的事（不许等用户追问）

先跑状态检查，根据结果走分支：

```bash
python "<本技能scripts目录>/setup_account.py" --status
```

- **已配置** → 直接问用户：「今天想写什么主题？要我先抓一批同领域的爆款标题参考吗？」
- **未配置** → 发送下面的「开通引导」，一步步带用户配置，不许跳步。

### 开通引导（未配置时必须原文发出，再等用户回复）

> 你的公众号凭证还没配好，只要复制粘贴两串字符就够了，我来跑剩下的：
>
> **第 1 步**：电脑浏览器打开 `mp.weixin.qq.com`，用你的公众号账号扫码登录
> **第 2 步**：左下角「设置与开发」→「基本配置」
> **第 3 步**：看到「开发者ID(AppID)」，复制发给我（wx 开头那串）
> **第 4 步**：同一页找「开发者密码(AppSecret)」→ 点「启用/重置」→ 手机收个验证码 → 生成后**立刻复制**发给我（只显示一次，关掉就没了）
>
> 小贴士：
> - AppSecret 是你公众号的钥匙，**只发在这个对话里**，别发到任何群里
> - 我拿到后只会存进你自己电脑，不上传任何地方

用户把 AppID 和 AppSecret 发来后，**AI 代跑**（不要让用户自己敲命令行）：

```bash
python "<scripts目录>/setup_account.py" --appid 用户填的 --secret 用户填的
```

脚本会自动向微信验证。如果报 **40164（IP 不在白名单）**，照抄脚本输出里的解决步骤发给用户（大意：打开 `open.weixin.qq.com` 扫码登录 → 「开发接口管理」→ IP 白名单 → 把报错里提到的 IP 加进去，保存等 1 分钟，让用户说声"好了"再重跑一次验证命令）。

### 密钥安全铁律

1. 用户的 AppSecret / API Key 只通过对话发给 AI，AI 用命令行参数传给脚本，**绝不写进任何要发布/分享的文件**。
2. 凭证只存在用户本机 `secrets/` 目录（该目录永远不打包、不发布）。
3. 打包/发布本技能前必须跑安检命令（见文末）。

## 三大功能与命令

### 功能一：爆款选题（可选，需红狐 Key）

```bash
python "<scripts目录>/hot_topics.py" --keyword 退休 --limit 10
```

输出当天该领域的爆款文章列表（标题+阅读量+点赞），存到当前目录 `hot_topics.json`。AI 拿这个当写稿参考：标题套路、切入点、读者情绪。

红狐 Key 获取：`redfox.hk` 注册 → 控制台 → API Key。配置：

```bash
python "<scripts目录>/setup_account.py" --redfox-key 用户的Key
```

没有红狐 Key 也能用整个技能——选题靠 AI 联网搜即可，跳过此步。

### 功能二：写稿（AI 自己干）

AI 根据主题+爆款参考写文章，存成 JSON 文件（**必须遵守防乱码铁律**：写文件用 UTF-8 + `ensure_ascii=False`）：

```json
{
  "title": "《标题》",
  "content": "<p>段落1</p><p>段落2</p>",
  "digest": "摘要（120字内）",
  "author": "作者名（最多4个汉字）"
}
```

硬性尺寸限制（超了微信直接报错）：
- 标题 ≤ 64 个汉字（建议 20 字内更吸睛）
- 摘要 ≤ 120 汉字
- author ≤ 4 汉字（超长报 45110）

### 功能三：存进草稿箱

```bash
python "<scripts目录>/publish_draft.py" --article article.json
```

脚本自动：生成封面图（标题前8字排版）→ 上传素材 → 存草稿箱。成功后用户去 `mp.weixin.qq.com` →「内容与互动」→「草稿箱」里查看，点「发表」才真正群发（**AI 永远不代替用户点发表**）。

先演练再真发（强烈建议新用户第一次用）：

```bash
python "<scripts目录>/publish_draft.py" --article article.json --dry-run
```

`--dry-run` 只本地生成封面和自检，不连微信，零风险。

## 常见报错速查（发给用户时用大白话解释）

| 报错 | 大白话 | 怎么修 |
|---|---|---|
| 40164 | 你的电脑 IP 微信不认识 | open.weixin.qq.com → IP 白名单 → 加上报错里的 IP |
| 40001 / 40125 | 钥匙不对（复制少了或重置过） | 重新复制 AppSecret，重跑 setup_account.py |
| 45003 / 45004 | 标题或摘要太长 | 缩短后重跑 |
| 45110 | 作者名太长 | 最多 4 个汉字 |
| 48001 | API 权限不够 | 个人未认证订阅号部分接口受限；草稿箱接口一般可用，若报此错需完成认证 |
| 乱码 | 编码链路坏了 | 本技能已内置 UTF-8 铁律，若还乱码检查是否用了旧脚本 |

## 依赖

`requests`、`pillow`。缺什么 AI 就自己装好再跑，别让用户装。

## 定时自动发稿（进阶，用户主动要才讲）

用 WorkBuddy 的「自动化/定时任务」功能：每天固定时间让 AI 跑「功能二+功能三」。提醒用户：草稿是存进去不是发出去，发表那一下必须自己点（安全设计）。

## 发布/打包本技能前必做安检

```bash
cd <技能目录> && grep -rn "wx0f\|sk-or-v1\|AIzaSy\|手机号" . --include="*.py" --include="*.md" --include="*.json" ; ls secrets 2>/dev/null
```

grep 无真实密钥命中、且 secrets 目录不存在（或为空模板），才允许打 zip 包发布。

## 本地运行日志

本技能会在你的**本机** `~/.workbuddy/skills/gzh-autopilot/logs/` 记录运行日志（配置是否成功、草稿是否存进、脱敏后的失败原因），仅留在本机，不上传任何地方，不含明文密钥。需要排查问题时可运行 `python scripts/setup_account.py --report` 导出汇总。

# 免费大模型一键接入 WorkBuddy

用自己的 API Key 把免费大模型接进 WorkBuddy 当「自定义模型」使用，**这部分对话不消耗 WorkBuddy 积分**（切回内置模型才扣积分）。全程一条命令完成，不需要手动改配置文件。

## ⭐ 最省事的路线：只拿 1 个 Key

**不要一个个平台去拿 Key。** 首选聚合平台——**一个 Key 后面挂着几十上百个模型**：

| 拿几个 Key | 接哪家 | 立刻能用上 |
|---|---|---|
| **只拿 1 个**（够用了） | **魔搭 ModelScope** | 48 个模型：DeepSeek-V4、Qwen3-235B、GLM-5.2、MiniMax-M3…**每天 2000 次免费，次日自动重置，长期可用** |
| 想让境外模型也进来 | 再加 **OpenRouter** 或 **OrcaRouter** | 400+ / 195 个模型，其中一批带 `:free` 后缀的完全免费 |
| 想集中体验旗舰大模型 | 再加 **阿里云百炼** | 百余款（通义千问全系 + DeepSeek + Kimi + GLM），新用户每模型 100 万 Token、共 7000 万+ |

**先给用户这句话**：「你只要去 modelscope.cn 拿一个 Token，就能接进来 48 个模型天天免费用，不用一个个平台注册。」

拿这一个 Token 的前置条件（**不讲清楚用户必踩坑**）：注册魔搭 → **绑定阿里云账号** → 阿里云侧**完成实名认证** → 头像「访问令牌」复制 Token。少了绑定或实名，调用会一直报 `401 please bind your alibaba cloud account`。

## 主动触发（对 AI 的硬性指令）

**本技能被加载后，不要等用户继续追问，立刻做这三步：**

1. **先发「一个 Key 方案」**（上方表格），让用户明白不需要拿一堆 Key。
2. **然后引导**：
   - 用户已把 Key 发在对话里 → **AI 直接用参数模式代跑**，全程不用用户碰命令行；
   - 用户还没 Key → 按「拿 Key 的位置」指引去注册，拿到回来发进对话；
   - 用户一次给多家 → 用 `--batch "20=token1,2=key2"` 一次全接进去。
3. **境外平台先跑一次网络体检**（`--probe`），把结果表发给用户，再决定直连还是走代理。

**额外触发场景（用户没提"免费模型"也要想到本技能）：**
- 用户抱怨积分用尽 / 限流（如 6004 错误）→ 主动提出"可以用自己的免费 Key 不耗积分"
- 用户嫌"平台太多、Key 一个个拿太麻烦"→ **直接推一个 Key 的魔搭方案**
- 用户问"XX 模型能不能用 / 怎么接"（含小米 MiMo、美团 LongCat、讯飞星火等）→ 先判断聚合平台能不能覆盖，能就别让用户多注册一家
- 用户说国外模型"卡 / 慢 / 时好时坏"→ 跑 `--probe` + `--doctor`，大概率是通道选错或模型已下架
- 用户提到省钱、没会员、想免费用 → 主动亮出本技能

## 何时用
- 用户想在 WorkBuddy 用免费大模型。
- 用户明确说「省积分 / 没有会员 / 不想付费」。
- 已有 Key 但配置不成功，或模型报 401/403/404/429 需要排错。
- 已接入的模型突然不能用了（多半是平台下架或免费池变动）。

## 一键接入（三种跑法）

**跑法 A：AI 代跑（用户已把 Key 发进对话时，优先用这个）**

```bash
# 只要一个 Key（推荐）
python scripts/setup_free_llm.py --provider 20 --key 你的魔搭Token

# 多平台一次接完
python scripts/setup_free_llm.py --batch "20=魔搭token,2=OpenRouter key"

# 不用写编号，脚本会按 Key 前缀自动认平台（ms- 认魔搭、sk-orca- 认 OrcaRouter 等）
python scripts/setup_free_llm.py --key 你的Key
```

- 平台编号见 `--list ALL` 或下方参考手册；`--provider` 可省（脚本按 Key 前缀猜平台，猜不出会提示）
- 可加 `--proxy http://127.0.0.1:50008`（默认 `auto` 自动探测，一般不用加）
- 可加 `--deep`：额外做一次流式实测，与 WorkBuddy 实际用法一致（更严格，稍慢）
- AI 跑完把实测结果汇报给用户：哪些模型 OK、延迟多少、写了哪个文件

**聚合平台会自动展开，而且是带替补的**：给聚合平台一个 Key，脚本会拉它的**实时在线清单**，按偏好挑出**数倍于目标量**的候选（目标是 5 个就实测 12~15 个），淘汰跑不通的，**只把通过的最快的 5 个**写进去。

**为什么必须多测几个**：免费聚合池常有"能列出来、却跑不出内容"的模型。魔搭实测就出现过 **HTTP 200 但 `choices` 为空**（共享池额度被瞬时吃满）——DeepSeek 全系、智谱全系、文心全系、阶跃全系一度全空。**只测 5 个的话可能一个都留不下。** 多测留替补后，实测 12 个通过 9 个，最终稳定写入 5 个可用模型。这类空响应通常**过一阵会自己恢复**，不是模型坏了。

**跑法 B：用户自己跑（交互模式，适合会命令行的用户）**

```bash
python scripts/setup_free_llm.py
```

流程（用户只需要做两件事：选编号、贴 Key）：
1. 菜单分两档：「首推：一个 Key 通吃多个模型」/「单家平台」，★ 标注最值得先接的
2. 可一次输多个编号（如 `20,2`），逐个贴 Key
3. 脚本自动：**探测本机代理 → 通道竞速 → 拉平台实时模型清单 → 并发实测 → 按延迟快慢写入** `~/.codebuddy/models.json` 与 `~/.workbuddy/models.json`（写入前自动备份为 `.bak-时间戳`，同 id 覆盖，并清理该平台已下架的旧条目）
4. 提示「完整退出并重开 WorkBuddy → 对话页模型选择器里挑刚写入的模型」

**跑法 C：先体检，再决定**

```bash
python scripts/setup_free_llm.py --probe      # 各平台 直连/各代理 通道 可达性+延迟对照表（不写配置）
python scripts/setup_free_llm.py --doctor     # 体检已写入的模型：哪些还活着、哪些已是死条目
python scripts/setup_free_llm.py --list 20    # 看某平台实时在线模型清单（魔搭/OpenRouter/OrcaRouter 不需要 Key）
```

## 解决「国外免费模型不流畅」

国外模型本身没问题，卡的是**通道**：

1. **代理自动探测**：不再要用户手动填端口。脚本自动读环境变量代理 + Windows 系统代理（注册表）+ 并发扫描本机常见代理端口（7890/7897/10809/1080/2080/8889/**50008**/20171…）。用户什么都不用配。
2. **通道竞速**：对同一个服务，直连和各代理**各打一枪**，取延迟最低的那条。结果是「谁快用谁」，而不是「有代理就一定走代理」——本机实测就出现过*Groq 直连更快、OpenRouter 走系统代理更快*的情况。选择结果按 URL 缓存，不会每个模型重测。
3. **按实测延迟排序写入**：通过实测的模型**从快到慢**写入配置。WorkBuddy 模型选择器里排在最上面的就是最快的那个，用户不用自己试。
4. **429/503 自动退避重试**：免费池撞限流是常态，脚本按 `retry_after` 退避重试 2 次，而不是直接判死。

**结论拿给用户看**：先跑 `--probe`，把那张对照表发给他——哪些平台直连就通、哪些必须挂代理、代理比直连快多少毫秒，一目了然。

## 免费额度与 429（必讲给用户）
- 撞到 429 = 限流，**不是坏了**：免费模型算力是共享池，高峰期谁都可能 429。
- 处理：切到列表里另一个免费模型（所以脚本会一次写入多个），或稍等重试。
- **魔搭的 2000 次/天是账号总量**，单模型另有上限（通常 200 次/天）；次日 0 点重置，长期可用，是最适合当日常主力的一家。
- 大多数平台的免费额度**不允许商用**，且输入内容会被平台记录 → 敏感数据别发给免费档。
- **火山方舟（豆包）多一步**：必须在控制台逐个「开通」模型，否则调不通。
- **智谱免费档限 1 并发**：单用户够用，同时跑多个 Agent 会撞限。
- **OrcaRouter 是第三方中转**，非官方直连，稳定性与合规性无保障，别放重要用途。

## 排错速查
| 现象 | 原因 | 处理 |
|---|---|---|
| **401 please bind your alibaba cloud account**（魔搭） | 没绑阿里云 / 阿里云未实名 | **不是 Key 的问题**：去 modelscope.cn 头像→账号设置→绑定阿里云，再完成实名 |
| 401 invalid key | Key 复制不完整 | 重新复制，注意前后空格 |
| 401 且 Key 看着没错（讯飞） | 用错了凭证：填了 AppID/APIKey | 要填控制台里的 **APIPassword** |
| 401（百炼） | 地域不对 / 没开通 / 未实名 | 控制台地域切「华北2（北京）」，点过「开通百炼」，完成实名 |
| 403 Forbidden（Groq/Cerebras） | Key 无效或该模型不对当前账号开放 | 换平台列表里的另一个模型 |
| 403 未开通（豆包/千帆） | 没在控制台点「开通」 | 去控制台开通该模型 |
| 404 unavailable for free | 该模型已退出免费池 | 重跑本平台（会自动清理），换其他模型 |
| 429 | 免费层/共享池限流 | 换同列表另一个免费模型；Groq/Mistral 是逐模型限流 |
| 国外平台时快时慢/超时 | 通道选错 | 跑 `--probe` 看对照表；必要时 `--proxy http://127.0.0.1:端口` |
| OpenRouter 网页打不开 | Cloudflare 人机验证卡国内浏览器 | 打不开网页不代表 API 不通，先跑 `--probe` |
| 模型选择器里有些模型不能用 | 平台下架但配置里还留着 | 跑 `--doctor` 体检，它会列出死条目 |
| 写入后模型列表没出现 | 没重启 WorkBuddy | 完整退出进程再打开 |
| 脚本中文乱码 | Windows GBK 控制台 | 脚本已内置 UTF-8 重配置，若仍乱码 `chcp 65001` 后重跑 |

# 每日招聘简报生成器

为求职者（典型：离校未就业毕业生）每日生成求职简报。任何人装了本 skill，跑一次首次引导后就能按自己的画像生成，不依赖特定会话、不依赖特定人。

## 首次使用引导（第一次必须做，之后的每日简报不需要重复）

**判断**：若本机没有 `config.json`（或用户明确说画像变了），**不要急着生成简报**，先主动开口引导，一次问清，问完把答案写入本机 `config.json` 再开工。引导要自然、口语化，不要一次抛十个问题（分 2-3 组问完即可）。

**必问清单**：

1. **简历**：「方便把简历发我吗？PDF/Word/图片都行。我只在本次会话里读它提炼你的技能关键词，帮你把岗位匹配做得更准。」
   - 用户发来后：解析简历，提炼出「技能关键词（语言/工具/框架/项目方向）+ 实习/项目经历 + 亮点和短板」，存进 `config.json` 的 `profile.resume_notes`（存本机）。
   - 用户暂时不发：跳过，用问答补齐画像，后续随时可以补发。
2. **城市/地域**：「想留在哪个城市？只看本地，还是外地好机会也可以？」（决定简报第 2 段的 ✅ 标注口径）
3. **方向**：「想投什么方向？嵌入式/FPGA/芯片/硬件/机器人/软件测试……有明确偏好还是都看看？」
4. **薪资期望**：「期望薪资大概什么范围？给个区间就行。」
5. **特殊要求（重要）**：「有没有硬性条件？比如——不接受出差/夜班、通勤不能超过多久、只想去大公司/研究所、家在某地所以只想在某片区、身体状况或其他需要照顾的情况。有什么说什么，我好提前过滤。」
6. **邮箱（可选）**：「简报要不要每天发到你邮箱？不发也行，直接在这里看。」

**引导完成后**：把所有答案写入技能目录 `config.json`（格式见下），然后告诉用户「画像已就绪，明天开始每天 X 点给你出简报」，再继续生成当日简报。

> 隐私说明：简历和所有个人信息只在用户本机读取和保存（config.json 仅落盘本机），**绝不上传 SkillHub、绝不含在分发包里**，简报正文也不会出现简历里的证件号/住址等信息。

## 本机配置（必做，含个人隐私，不要写进本文件）

在技能目录或用户主目录放一个 `config.json`，示例：

```json
{
  "name": "张三",
  "email": "zhangsan@example.com",
  "profile": {
    "city": "武汉",
    "degree": "2026届本科",
    "major": "电子与计算机工程(ECE)",
    "salary": "13-22K",
    "status": "离校未就业, 处于2年择业期(央国企按应届对待)",
    "directions": "嵌入式 / FPGA / 芯片半导体 / 硬件 / 机器人 / 央国企科技岗",
    "strategy": "央国企秋招主攻 + 中型上市公司社招补录 + 内推 + 外包兜底",
    "local_priority": "本地(光谷)优先, 标注 ✅",
    "special_requirements": "不接受长期出差; 通勤1小时内; 优先研究所和有编制感觉的国企",
    "resume_notes": "技能: C/Python, STM32, Verilog, 有XX比赛项目; 短板: 无实习经历, 面试表达偏弱"
  }
}
```

找不到 `config.json` 时，先跑上面的「首次使用引导」补齐；用户坚持跳过则回退到内置中性默认画像（示例：2026 届、武汉、嵌入式/FPGA 方向），保证开箱即用。

> 隐私说明：你的姓名、邮箱、学校等只存在你本机 `config.json`，**绝不上传 SkillHub、绝不含在分发包里**。

## 默认筛选口径（可在 config 覆盖）

- 地域：武汉本地（光谷）优先，标注 ✅；全国可投次之。
- 方向：嵌入式 / FPGA / 芯片半导体 / 硬件 / 机器人 / 央国企科技岗。
- 身份：离校未就业毕业生处于 2 年择业期内，**央国企/公务员/事业单位按应届对待**。

## 行文基调（硬性，与岗位数据同等重要）

简报的读者是一个正在找工作、可能有点焦虑的年轻人（或替孩子操心的家长）。**纯信息罗列是不合格的**，每份简报必须做到：

1. **开场一句暖心话**：不是空话鸡汤，而是结合当日情境的鼓励。例如连续几天没面试邀约时写「投出去的简历没有回音，不一定是你的问题——8月底正是 HR 筛简历堆积期，坚持投，9月第一周是回复高峰」。
2. **每段穿插小贴士/注意事项/小提醒**（至少 2-3 处，位置自然，用引用块 `>` 或 💡 标出）：
   - 求职干货型：网申填表技巧、简历关键词怎么改才能过机器筛、央国企报名截止规律；
   - 避坑型：这类岗位常见坑（外包驻场身份、试用期辞退率、培训贷骗局）；
   - 打气型：数据化鼓励（本周已覆盖 N 家公司、按转化率估算下周约有 X 个笔试）。
3. **岗位针对性**：有 `resume_notes` 时，重点岗位后面标注匹配点，如「（你的 STM32+Verilog 和这个岗位 JD 高度重合，值得优先投）」；明显不匹配的岗位宁可不放，不凑数。
4. **尊重特殊要求**：`special_requirements` 里写明的硬性条件（不出差/通勤半径等）严格过滤，拿不准的岗位标注提醒。
5. **结尾行动建议 + 一句打气收尾**：先给今天该投哪几家的明确清单，再用一句真诚的话收尾（可以引用一句朴素的道理，但禁止空洞口号）。

> 尺度：暖心但不油腻，干货为主、情绪为辅。让读者读完的感觉是「有人认真在帮我」，而不是「群发的模板」。

## 简报结构（8 段，固定顺序，不可省略）

1. **开场**：称呼「{name}同学」，一句当日行情 + 一句暖心的鼓励。
2. **本地优先 ✅**：{city}本地岗位，逐条标 ✅，含公司/岗位/薪资/门槛，重点岗标匹配点。
3. **央国企 / 事业单位**：可投的央企、国企、银行科技岗（强调应届身份有效）+ 报名注意事项。
4. **芯片 / 半导体**：本地及全国龙头（长江存储、烽火、长飞、高德红外、中芯等）。
5. **机器人 / 具身智能**：当年届校招（离校未就业补录可试）。
6. **嵌入式 / FPGA / 硬件**：海康、中科芯、清微、欣锐、联眺等。
7. **昨日后备（复推）**：昨日未投的重点岗，编号续接，附「为什么还值得投」。
8. **行动建议 + 打气收尾**：今日优先投哪几个、用哪个渠道，最后一句真诚的话。

## 去重规则（硬性）

- 生成前**必须先读昨日简报**（默认路径 `招聘简报_YYYY-MM-DD.md`，按当天日期往前找最新一份）。
- 提取昨日全部公司+岗位，新简报剔除完全重复项，保留全新岗位；昨日重点未投岗转入第 7 段复推。
- 每日规模目标：**60 条新岗位**，武汉本地约 30-45 条。

## 数据源（按可用性降级）

- **首选 WebSearch**：搜「2027 届校招 武汉 嵌入式 / FPGA / 芯片」「XX 公司 2027 校园招聘」「央国企 2026 届补录」。
- **次选 WebFetch**：抓公司校招官网、国聘网、前程无忧专题页核实细节。
- 可靠性标注：每条注明来源（官网/新闻/招聘平台），不确定性高的标「待核实」。

## 邮件发送（可选，需 Agent Mail 已授权）

- 收件与主题从本机 `config.json` 的 `email` 字段读取，主题形如 `【每日求职推荐】{city} - YYYY-MM-DD`。
- 用 `mcp__agent-mail__SendMessage`，`to` 为对象数组 `[{"email":"<config.email>","name":"<config.name>"}]`，`body_format: MARKDOWN`，`skip_confirmation: true`。
- Agent Mail 未授权时跳过邮件，仅本地 `present_files` 交付 markdown。

## 执行流程（AI 被加载后立即跑，不要等追问）

1. **读 `config.json`**：不存在则先走「首次使用引导」（要简历、问城市/方向/薪资/特殊要求），写好 config 再继续。
2. 确定今天日期，找昨日简报去重基准。
3. WebSearch 抓取 7 大方向当日新岗，按画像+特殊要求+简历技能关键词筛选，本地优先、宁缺毋滥。
4. 按 8 段结构+行文基调撰写简报正文（markdown，含穿插的小贴士/提醒/鼓励）。
4. 调用 `scripts/gen_brief.py` 落盘为标准文件：
   - 若 AI 已写好完整正文：`python scripts/gen_brief.py --date YYYY-MM-DD --raw-file 草稿.md --out 招聘简报_YYYY-MM-DD.md`
   - 若用结构化数据：`python scripts/gen_brief.py --date YYYY-MM-DD --data brief.json`
5. `present_files` 本地交付；Agent Mail 可用则发邮件。
6. 调 `scripts/usage_logger.py` 的 `log_event("job-brief-generator","brief",success=True/False,...)` 在用户本机记录一条运行日志（仅落盘，不上传）。

## 何时用
- 用户说「生成今天的求职简报」「帮我儿子找武汉工作」「每日招聘推荐」。
- 配合自动化：在 WorkBuddy 建每日 10:30 定时任务，prompt 写「调用 job-brief-generator 生成今日简报并发邮件」。

## 依赖
- WebSearch / WebFetch（联网，国内站点直连即可，无需代理）。
- 可选 Agent Mail connector（发邮件用）。
- Python 3 标准库（usage_logger 仅标准库）。

# 合同风险 + 面对面谈判：全流程里风险最高的两步

前面所有工作（抓取、核验、问询、议价）都是**为了走到这两步**。而这两步有个共同特点：
**AI 到不了现场、也签不了字，所以必须提前把"看什么、防什么、怎么谈"交到人手里。**

---

## 一、合同风险扫描（签约前必跑）

### 为什么不能"让学生自己看合同"

门禁清单写着"合同 8 项逐条核对"，但给一个意大利语不熟的学生一份 6 页合同让她自己找
"退租通知期""押金退还条件"——**等于没做**。让 AI 直接读又不可靠（会编）。
正确做法：**用 `contract_check.py` 按关键词把条款位置挖出来，逐条附原文摘录，由人复核。**

```bash
# PDF 先转文本（阅读器复制 / 或让 AI 转），再喂进来
python scripts/contract_check.py --file contratto.txt
python scripts/contract_check.py --file contratto.txt --json out.json   # 结构化输出
```

### 它做什么 / 不做什么

| 做 | 不做 |
|---|---|
| 定位 13 类关键条款（命中就给**原文摘录**） | ❌ 不判断条款是否合法 |
| 标出合同里**没找到**的条款（= 要去问房东） | ❌ 不构成法律意见 |
| 命中常见**红旗表述**（不退押金、只收现金、通知期长…） | ❌ 不代替律师/租客协会 |
| 每条给"为什么重要 + 该怎么办" | ❌ 不替你决定签不签 |

**纪律**：**找不到就明说找不到**（标 ✖），绝不因正则没匹配上就假装"没问题"。
每条判定都附原文，**不让人盲信结论**。

### 13 类必查条款

退租通知期 `preavviso/disdetta`｜押金 `deposito cauzionale/caparra`｜
合同类型 `transitorio/4+4/concordato`｜是否注册 `registrazione`｜
租期 `durata/decorrenza/scadenza`｜租金与调租 `canone/ISTAT`｜
杂费 `spese/oneri accessori`｜转租接手 `subaffitto/subentro`｜
维修责任 `manutenzione`｜违约金 `penale`｜双方税号 `codice fiscale`｜
房屋与产权人 `catastale/proprietario`｜付款与收据 `pagamento/ricevuta`

### 常见红旗（脚本命中即高危）

| 红旗表述 | 为什么危险 |
|---|---|
| `non rimborsabile`（不退还） | 押金可能被吞 |
| `senza registrazione`（不注册） | 办不了居留 + 押金无凭据 |
| `vietato il subaffitto / subentro` | 退租时无法找接手人，被动 |
| `solo in contanti` / `in contanti` | 现金无凭证，退押金时无据可依 |
| `preavviso di 6 mesi` | 通知期过长，对短租极不利 |
| 押金达 `3 mensilità` | 偏高，需充分理由 |
| `imposta di registro a carico del conduttore` | 注册税推给租客（通常房东承担） |
| 注册义务 `a cura del conduttore` | 注册应由房东办，推给租客属异常 |
| `spese straordinarie ... carico del conduttore` | 结构性大修推给租客，异常 |
| `caparra confirmatoria` | 定金性质，违约可能被没收 |
| `rinuncia al preavviso` | 放弃通知期，单方吃亏 |

> **红线提醒**：押金上限、通知期长短这类**合法性**问题各国不同，脚本只负责"指出位置"，
> 是否合法请学校国际办或当地**租客协会**（意大利 SUNIA / UDI，多数对学生会免费）复核。

## 二、面对面谈判：AI 不在场，只能给你一套"带在身上的提示"

邮件/站内信谈判可以自动化（受 `mandate.json` 授权表约束）。
但**看房、当面谈、签约当天**这三件事 AI 到不了场。以下是给人看的风险与技巧。

### 出发前：把三样东西写在手机上

1. **授权表底线**（`mandate.py brief` 的输出）—— 最高能接受多少、哪些必须写进合同。
2. **合同必查项**（上面 13 类里，你的房东最容易含糊的那几条）。
3. **不能当场做的事**（见下方红线）—— 看房当天最容易被"氛围"推着做错。

### 现场风险清单（按"最容易吃亏"排序）

| 风险 | 现场怎么表现 | 怎么应对 |
|---|---|---|
| **被催付定金** | "很多人抢""今天不定就没了" | 没看房/没见到合同，**一分钱不付**。可以表达兴趣，但把付款推到"看完合同、核实房东"之后 |
| **房东否认要签合同** | "先住进去，合同以后补""不用那么麻烦" | 没有注册合同 = 影响居留 + 押金无凭据。**没合同不入住** |
| **押金收取不规范** | 要现金、不给收据、转到个人而非房东账户 | 优先银行转账留流水；现金必当场出签字收据；转账前核对收款人 = 合同主体 |
| **合同类型含糊** | 写长租类型却只让你住 4 个月 | 坚持 `transitorio`；类型不符就问清为什么 |
| **口头承诺不入合同** | "可以提前走""押金肯定退""可以找人接手" | **口头承诺一律要求写进合同**（尤其 subentro、通知期、押金退还） |
| **费用口径被模糊** | "杂费不多你放心" | 要具体数字与包含项（水/电/气/网/暖气/物业），写进合同 |
| **身份/合租限制** | 现场才说"只租女生""不接受某国籍" | 问询第一封就该问清，避免白跑 |
| **看房时间/地址被临时改** | 反复改约、要求去非房源地址见面 | 谨慎，最好有人陪同，地点坚持在房源本身 |

### 现场技巧

- **先给房东"你不会空房"的方案，再谈你的需求。**（同 `objection_handling.md` 的核心原则）
- **只对"已在授权表内"的条件当场松口。** 超出边界的一律说"我回去确认一下"——这句话不丢分。
- **能拍照就拍**：合同页、押金收据、房屋现状（入住前把所有瑕疵拍下来，退租时是证据）。
- **带一个能帮你看合同的人**（同学/学长/国际办公室）。意大利语不熟时，这一点比省钱重要。
- **签约当天不付全款押金**，除非：合同已注册 + 房东身份已核 + 收款人与合同主体一致。

### 三条"当场绝不能做"（与技能红线一致）

1. ⛔ **不签字** —— 除非隐私/条款都已核对清楚。
2. ⛔ **不付款** —— 没实地看房、没核实房东，一分不付。
3. ⛔ **不提交证件原件** —— 复印件够用；原件只在正式注册环节、且当面取回。

## 与其它模块的衔接

- 签约前 → 跑 `prep_check.py --stage before_signing` 确认门禁全绿。
- 拿到合同文本 → 跑 `contract_check.py` 逐条扫。
- 出发看房前 → 跑 `mandate.py brief` 把底线写到手机上。
- 房东提异议 → 查 `objection_handling.md`。

# 资料与付款准备：签约当天要什么，今天就办完

> 这一篇对应的坑是"到了那一步才发现没做"。海外租房真正卡人的从来不是房源，
> 是**材料没备齐、钱打不过去、没人给你担保**。这三样必须在找房之前解决。

## 三样东西决定你能不能租到房

| # | 要什么 | 不带会怎样 | 提前多久 |
|---|---|---|---|
| 1 | **身份号** | 房东可以直接拒；签不了注册合同；办不了居留 | 1–2 周（各国叫法见 country_packs.md） |
| 2 | **能到账的付款通道** | 房东要今天付押金，你的钱三天后到 = 房源没了 | 找房前就打通 |
| 3 | **可信度证明** | 被当成"随时会跑的外国人" | 1 周内凑齐 |

## 一、付款通道：IBAN 是核心

**IBAN**（International Bank Account Number）= 收款账号的"国际标准写法"，欧洲转账都用它。
格式：`国家码2位 + 校验位2位 + 银行代码 + 账号`，例如意大利 27 位、德国 22 位。

**关键认知：IBAN 本身不告诉你钱打给谁。** 它只保证"这个号码格式是对的"。
假房东最容易在这里骗人——给的账号格式都对，但户主不是房东。

### 付押金前的四步核验（顺序不能换）

```
第 1 步  跑格式与校验位      python scripts/iban_check.py <IBAN>
        └ 不通过 → 停。让房东重发，一个字一个字对。
第 2 步  看国家与币种        └ 非欧元/非 SEPA 会慢、会扣费、追不回
第 3 步  转账页核对收款人姓名  ← 这一步最关键，工具替不了你
        └ 银行 App 输入 IBAN 后会显示户名，必须与合同上的房东/中介名一致
第 4 步  只付合同主体         └ 合同写谁，钱就付给谁。第三方账户一律拒。
```

第 3 步是本篇最值钱的一句话：**格式校验能挡住"抄错/乱编"，只有户名比对能挡住"假房东"。**

### 常见的坑

| 坑 | 表现 | 处理 |
|---|---|---|
| 押金打给"朋友/亲戚的账户" | "我在国外，先打给我表弟" | 直接拒。合同主体是谁就付给谁 |
| 户名与房东名不一致 | 转账页显示的是个公司或个人，合同上却是另一个 | 停下来要书面授权（委托书） |
| 只收现金 | "现金方便，不用转账" | 现金必须当场出收据、签字、写清退还条件 |
| 要求先付"看房定金" | "很多人抢，先付 50 欧锁房" | 没看房不付钱，这是红线 |
| 汇率与手续费被吃掉 | 非欧元国家到账金额少一截 | 先算清"到账多少"，别只算"我汇多少" |

## 二、一套资料包（做成一个文件夹，手机也能调出来）

**身份类**
- 护照信息页、签证/居留页
- 录取通知 / 在读证明（**要带学校名、院系、有效期**，这是你最有力的可信度证明）
- 证件照（电子版，多尺寸）
- 身份号文件（税号/NIE/BSN/PESEL…按国家）

**财务类**
- 能刷国际支付的银行卡（+ 手机银行能立刻转账）
- 资金来源证明（奖学金/资助/父母转账记录/银行流水）—— 房东要担保时就用它
- 押金 + 首月租的现金/可用额度（按 `A_hard.budget_month_total_max` 备足）

**证明类（提高通过率）**
- 学校国际办公室介绍信（**最有效、最便宜**，先要这个）
- 学校住房办公室/学联的联系方式
- 已入住学长的推荐（愿意的话让他给房东发一条消息）

**给房东的一段标准化自述**（每次问询都用同一套，见 `assets/templates/messages.json`）：
> 我是 XX 大学（院系）的交换生，租期 X 月到 Y 月，全程不会中断退租；
> 已有身份号，可以签正规注册合同，押金可以立刻付。学校可出介绍信。

## 三、填注册表/申请表：字段对照

报房源板、中介平台、群组申请表，字段名字各国不同，但**要的东西是同一批**。
填之前先对照这张表，避免卡在某个看不懂的字段上：

| 各国常见字段 | 中文含义 | 填什么 | 注意 |
|---|---|---|---|
| Nome / Vorname / Prénom / Nombre | 名 | 护照名 | 与护照**完全一致** |
| Cognome / Nachname / Nom / Apellidos | 姓 | 护照姓 | 中国学生别把姓填到名里 |
| Data di nascita / Geburtsdatum | 出生日期 | 年-月-日 | 各国顺序不同，注意 |
| Codice Fiscale / Steuer-ID / NIE / BSN / PESEL | 身份号 | 已有就填，没有写"in corso"（办理中） | 没号不等于不能问，别不敢联系 |
| Documento / Passaporto | 证件 | 护照号 | 上传页往往要照片 |
| Università / Hochschule | 学校 | 学校全称 + 院系 | 用官方英文/当地语言名 |
| Periodo / Zeitraum / Durée | 租期 | 起止日期 | 写清"到某月止"，别只写月数 |
| Numero di telefono | 电话 | 带国家码 | 意大利 +39 |
| Conto / IBAN | 收款或付款账号 | 一般不填给房东，是你要核对方的 | 别在表单里裸填自己的完整账号 |
| Garante / Bürge | 担保人 | 没有就写学校介绍信方案 | 先问对方为什么需要 |

**两个纪律：**
1. **姓名与护照完全一致**（拼音别自己改顺序），不一致会在合同/居留环节炸。
2. **不确定的字段不要瞎填。** 写"non lo so / to be confirmed"再附一句说明，比填错好——
   填错的信息会一路带到合同上。

## 四、把这一步接进门禁

```bash
python scripts/prep_check.py --stage now          # 看阶段 0 还有哪块没办
python scripts/prep_check.py --mark documents done
python scripts/iban_check.py <房东给的IBAN>        # 付钱前必跑
```

阶段 0 的 `blocking=true` 项没做完，后面的看房/签约都不要推进。
原因很简单：**材料不全的时候去看房，看中了也签不了，等于白跑。**

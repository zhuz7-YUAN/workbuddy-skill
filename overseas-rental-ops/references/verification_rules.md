# 房源核验规则（防止把假消息／旧消息当真）

## 第一原则：索引页不是事实，详情页才是事实

| 页面 | 性质 | 能不能下结论 |
|---|---|---|
| 搜索列表页 / 摘要页 / 社交帖子流 | **索引**，字段是从别处抄来或缓存的历史值 | ❌ 不能 |
| 房源详情页 / 原帖 | **事实**，房东自己维护 | ✅ 只有这里能 |

实测数据（2026-09-25，特伦托官方学生房板 trent.operauni.tn.it）：
列表页标"空置"的 17 套，进详情页核实后 **9 套实际已被占用**（滞后率 53%）。
另有 81 条标"空置"的房源里，只有 17 条被核实过——**覆盖率本身就是风险指标**。

**硬规则**：没打开过详情页的房源，不得写进任何"可以联系"的清单。

## 六个字段，一个都不能省

### 1. 地址 + 邮编(CAP) + 城市
- 详情页首行形如 `Via Santa Maria 44 - 38068 - Rovereto`
- **必须核对城市**：官方房源板往往覆盖整个省，不只是目标城市
- 意大利邮编速查（特伦托）：`38121/38122/38123/38100` = 特伦托市；
  `38068` = Rovereto（25 km 外）；`38057` = Pergine；`38061` = Ala
- 踩过的坑：把 Rovereto 的房子当成"特伦托市中心 15 分钟"，租客点开才发现 25 公里

### 2. 起租日（意大利语 `Libera da:` / 英语 `Available from:`）
**这是起租日，不是"空置起始日"**。三种情况三种处理：

| 情况 | 含义 | 处理 |
|---|---|---|
| 日期 **晚于今天** | 现在不能住 | 标「X 年 X 月起可住」，**禁止**放进"现在能住"清单 |
| 日期 **早于今天** | 现在可住，但要看空了多久 | 算空置月数，见下方"僵尸房源" |
| **空白 / 缺失** | 未知 | 标「起租日未标注，需确认」，按未核实处理 |

踩过的坑：一条 €350 的房子实际 `Libera da: 30/08/2027`，被标成"可立即入住"——早了 11 个月。

### 3. 每月杂费（意大利语 `Spese extra:`）
意大利学生房常见 €80–150/月的物业+水电网费，**必须并入总成本**。

**报价一律写三栏：`租金 €X + 杂费 €Y = 月总成本 €(X+Y)`**

踩过的坑：一条标 €330 的房子，`Spese extra` 是 €150/月，真实月支出 €480——低报 45%，
对方一打电话就会觉得"你发的信息是假的"。

### 4. 最短租期（`Permanenza minima:`）
- 房源板满屏都是 `12 mesi` / `1 anno` / `Un anno` / `annuale`
- **关键错配**：交换生通常只租 4–6 个月 → 即使房子空着也签不了
- 处理：标 >6 个月的，**不得直接推给租客**，必须先走"问询"流程
  （问能否缩短 / 能否接受转租 subentro），拿到肯定回复才能推
- 谈判两级台阶见 `objection_handling.md`

### 5. 性别限制
- 房间条目名直接带 `femminile`（女生间）/ `maschile`（男生间）
- 正文可能出现 `SOLO RAGAZZE` / `solo donne` / `per studentesse`
- 同一公寓多间房时，**逐间**标注哪间 `Libera`（空）、哪间 `Occupata`（占）
- 踩过的坑：3 间房的公寓只有"女生间"空着，却被写成"3 房公寓 1 间空"

### 6. 押金与合同类型（`Cauzione:` / `Tipo contratto:`）
- 押金常见 1–2 个月，要提前备好现金流
- `CONTRATTO DI LOCAZIONE DI NATURA TRANSITORIA`（临时性质租赁合同）比
  `contratto annuale` 更容易谈到短租——**优先找这种合同类型的房源**
- 合同必须在税务局注册，否则影响居留/签证材料

## 僵尸房源：挂了一年以上的"空置"

判定：起租日早于今天 **超过 6 个月**，且仍在标"空置"。

含义不是"没人要"，而是**房东早就不看这块了**——信息过期、人也联系不上。
（实测：Lorenzo 标 `01/12/2024`＝空置 21 个月、Venezia 87 标 `22/09/2025`＝空置 12 个月）

处理：标「⚠️ 僵尸房源（已空置 N 个月），别抱期望」，排序靠后，不要占用主推位置。

## 时效性：C2C 渠道（Facebook 群 / 分类广告）的另一套规则

C2C 帖子和房源板不一样：**房子会在几小时内成交**。

- 帖子发布时间 > **12 小时**，或评论区已出现 2 条以上
  `ti ho scritto` / `I wrote you` / `contattato`（已私信）→ 标
  「⚠️ 大概率已租走（发布 X 小时、已 Y 人私信），仅作备用」
- 只有发布 **< 6 小时且无抢单评论** 的才算有效机会
- 帖子仍然存在 ≠ 房子还在。**帖是真的，房没了**——这是最难判断、也最容易让租客白跑的一类

## 判定表（把每条房源归到三档）

| 档位 | 条件（全部满足） | 去向 |
|---|---|---|
| ✅ **已核实可联系** | 详情页读过 + `Stato: Libera` + 起租日 ≤ 今天 + 最短租期可谈且房东已肯定回复 + 已确认能看房 | 进主推清单 |
| ⏳ **已问待回** | 详情页读过 + 已发出问询 + 48 小时内未回 | 合并成一条，不铺开 |
| ⛔ **未核实 / 已排除** | 只读过索引页 / 城市不在目标范围 / 起租日在未来 / 已占用 / 僵尸房源 | **不进给租客的日报**，只留在内部日志 |

## 核验动作清单（每条房源逐项打勾）

```
[ ] 详情页打开过（不是列表页）
[ ] 地址含 CAP 且城市在目标范围
[ ] 起租日已读，且已判 past/future/blank
[ ] Spese extra 已读，月总成本已算
[ ] Permanenza minima 已读
[ ] 性别限制已读，多间房已逐间标注
[ ] 押金与合同类型已读
[ ] 空置月数已算（>6 标僵尸）
[ ] 若为 C2C 帖子：发布时间与抢单评论数已核
```

# 谈判授权表：哪些能松、哪些不能松

## 为什么必须先做这张表

"跟别人谈判也是重复谈判"这句话的根因不是话术不够，是**每次都得重新想一遍"我到底能退到哪"**。
把它一次问清楚、写成授权表，后面每一轮谈判都是查表执行，不用重新决策。

而且这张表还能反过来**约束 AI**：没有授权的事情不许替用户答应。

## 访谈提纲（四条线，逐条问）

### A 线 · 硬约束（不可谈，越线即放弃）

| 项目 | 要问出什么 |
|---|---|
| 预算 | **绝对上限**是几欧/月（按月总成本算），超过多少就直接放弃 |
| 地点 | 通勤上限多少分钟、哪些区域完全不接受 |
| 租期下限 | 最短能接受几个月（低于这个数就没意义） |
| 租期上限 | 最晚住到哪天（超过就是白付钱） |
| 合同 | 是否**必须**正规注册合同（办居留的通常=必须） |
| 性别/身份 | 只接受什么类型的房源（如只限女生、只接受学生公寓） |

### B 线 · 可谈／可让（有弹性，按梯度让）

| 项目 | 要问出什么 |
|---|---|
| 价格 | 可以从上限往下让多少欧、有没有心理价位 |
| 租期 | 房东要求更长时，最多能接受几个月；能不能接受"住满 + 自己找接手的" |
| 起租日 | 能提前多久起租（提前锁房 vs 省钱） |
| 位置 | 通勤上限能不能放宽 10 分钟换便宜 |
| 房型 | 单间 vs 双人间床位、带不带家具，能不能接受 |
| 杂费 | 含不含账单能不能接受（用总成本算） |

### C 线 · 可用的筹码（拿去换条件）

| 筹码 | 说明 |
|---|---|
| 立刻签约 + 立刻付押金 | 房东最想要的是确定性，这条最值钱 |
| 一次性预付 2–3 个月 | 换掉"你没担保/没收入证明"的顾虑 |
| 我负责找接手的（subentro） | 换掉房东"到期空房"的风险，**谈短租的主武器** |
| 整段不中断 | 明确"不会中途退租"，房东不用重新招租 |
| 学生身份 + 学校文件 | 降低房东对你"会不会赖账"的怀疑 |

### D 线 · 绝对不让（红线，遇到就退出）

- ❌ 没实地看房就付款
- ❌ 不签合同／私下住（影响居留、押金无凭据）
- ❌ 付给非合同主体（假房东风险）
- ❌ 只收现金不开收据
- ❌ 押金超过用户设定的上限几个月
- ❌ 承诺用户做不到的租期

**D 线由用户设定，AI 不得自行放宽。** 这是 `mandate.json` 里 `D_red_lines` 的用途；
`mandate.py check` 会在 D 线被关掉时报错。

## 输出：让步梯度表（谈判时按顺序执行）

把 A/B/C/D 合成一张表，谈判时从第 1 档开始让，一档一档往下，绝不跳档、绝不越 D 线：

```
第 1 档（最轻）：承认对方条件合理 + 表达强烈意愿 + 强调"我能立刻签、立刻付"
第 2 档：可让部分价格/位置弹性 ↔ 换对方接受租期
第 3 档：一次性预付 2 个月 ↔ 换掉担保要求
第 4 档：承诺自己找接手的（subentro）↔ 换掉"12 个月起租"
第 5 档（最重）：接受略超心理价位（仍在预算上限内）↔ 换立刻成交
—————————————————————————————————
⛔ 到此为止。再往上就是 A 线/D 线，直接放弃，不要为了成交破线。
```

## 使用方式

```bash
# 1) 生成模板，逐项填写（AI 会先访谈你，再落表）
python scripts/mandate.py init --out mandate.json

# 2) 校验：有没有漏填、有没有自相矛盾（预算上限 < 心理价位 / 租期下限 > 上限 …）
python scripts/mandate.py check --file mandate.json

# 3) 输出"谈判授权简报"——可以直接贴给 AI 或自己谈判时看
python scripts/mandate.py brief --file mandate.json
```

**纪律**：`mandate.py brief` 的输出就是谈判的授权边界。
超出这个边界的话术，AI **不许**写进发给房东的消息里。

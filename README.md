# WorkBuddy Skills / WorkBuddy 技能集

> 面向 WorkBuddy（AI 助手桌面端）的实用技能合集，均已发布在 [SkillHub](https://skillhub.cn)。每个文件夹是一个独立 skill，包含 `SKILL.md`（技能说明）与配套脚本/参考资料。
>
> A collection of practical skills for WorkBuddy, all published on SkillHub. Each folder is a standalone skill with a `SKILL.md` plus supporting scripts and references.

## 安装方式 / Install

把对应文件夹复制到 WorkBuddy 的技能目录即可：

- 用户级：`~/.workbuddy/skills/<skill-name>/`
- 项目级：`<workspace>/.workbuddy/skills/<skill-name>/`

或直接在 WorkBuddy 对话中让 AI 加载对应的 `SKILL.md`。

## 技能列表 / Skills

| Skill | 用途 |
|---|---|
| **ai-council** | 多模型决策陪审团：同一问题同时发给多家大模型独立作答，按证据权重汇总共识与分歧 |
| **free-llm-setup** | 一键把免费大模型（魔搭/OpenRouter 等）接进 WorkBuddy 当自定义模型 |
| **gzh-autopilot** | 公众号自动驾驶：找选题、写稿、自动封面、存草稿箱一条龙 |
| **job-brief-generator** | 每日招聘简报生成器：面向应届生的本地化求职情报，可定时发邮箱 |
| **overseas-rental-ops** | 海外（欧洲为主）学生租房全流程作业包：抓取、谈判、防骗、落地 |
| **stock-landmine-detector** | 个股排雷器：年报排雷 7 步法 + 一票否决信号，自动产出 HTML 报告 |
| **wechat-draft-safe-publish** | 通用中文 JSON 防乱码：杜绝 GBK/UTF-8 不匹配导致的中文乱码 |
